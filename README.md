# Copilot CLI — JoseloFarias fork

Fork de herramientas CLI relacionadas con GitHub Copilot, mantenido por **JoseloFarias** para evaluación e integración en flujos de desarrollo desde terminal.

## Objetivos

- Mejorar uso desde Termux/Linux y automatizaciones reproducibles.
- Mantener compatibilidad con upstream sin ocultar cambios propios.
- Evitar secretos embebidos y permisos innecesarios.
- Preservar atribuciones y licencia del proyecto original.

## Estado

Proyecto en evaluación/mantenimiento.

## Uso

```bash
git clone https://github.com/joselofarias-byte/copilot-cli.git
cd copilot-cli
```

Siga los scripts y requisitos presentes en el repositorio para la instalación concreta.
